# 태스크: user-quota-deduct (사용자 쿼터 차감)

## 절차
선행 노드 `leave-request-generate`가 생성한 차감 요청(하단 컨텍스트)을
입력으로 사용자별 휴가 쿼터를 차감하라.

1. 요청 건별로 사용자 잔여 쿼터를 확인하고 차감을 수행하라.
2. 처리/실패 건수를 집계하라.

## 규칙
- 멱등성: 이미 차감된 요청은 건너뛴다.
- 부분 실패 시 실패 건 목록과 사유를 산출물에 명시하라.
  실패 건이 하나라도 있으면 FAILED 로 판정한다 (후속 부서 집계가
  불완전한 데이터 위에서 돌면 안 된다).

## 판정
전 건 차감 완료 시 SUCCEEDED, 부분 실패 포함 처리 불가 시 FAILED.
