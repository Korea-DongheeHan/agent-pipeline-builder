# 태스크: leave-request-generate (휴가 쿼터 차감 요청 생성)

## 절차
1. 이번 배치 주기의 휴가 사용 내역을 조회하라.
2. 내역별 쿼터 차감 요청 레코드를 생성하라.
3. 생성 건수와 대상 요약을 산출물에 기록하라.

## 규칙
- 멱등성: 같은 주기 재실행 시 요청이 중복 생성되면 안 된다.
- 대상이 0건이어도 정상 종료(SUCCEEDED)다 — 0건임을 명시하라.

## 판정
요청 생성 완료 시 SUCCEEDED, 조회/생성 오류 시 FAILED.
GRAPH_OUTPUT 에 생성 건수를 보고하라. 예: GRAPH_OUTPUT: {"generated": "42"}
